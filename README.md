# AI Agents for Bharat

This repository contains the code, notes, and short demos for the "AI Agents for Bharat" LinkedIn series.
The series explores building and evaluating simple AI agents for India-focused scenarios (like phone-call data,
multilingual handling, and evaluation tools). The repo is organized so readers can open a folder for each post,
run small examples, or reuse helper code.

Quick map:
- `packages/` — small reusable code pieces (audio processing, text tools, evaluation helpers)
- `notes/posts/` — write-ups and reproducible notebooks for each LinkedIn post
- `datasets/` — information on where to get public datasets and how to handle them safely
- `docker/` — notes and Dockerfiles (optional) for reproducible demos
- `tools/` — helper scripts (formatting, simple utilities)

How to use:
1. Unzip the repo or open it in a file explorer.
2. Read `notes/posts/<post>/README.md` to see what each post shows.
3. Use the small examples and the `packages/` code as starting points.

This is a starter skeleton — fill each folder with your post content as you write posts.
