# How to contribute (Simple steps)

Thank you for wanting to help!

Basic guide:
1. Read the post folder you want to improve (notes/posts/*).
2. If you want to suggest a change, open an issue describing the idea.
3. If you want to submit a small change:
   - Make a copy of the repository or fork it on GitHub.
   - Add your change in a clear folder or file.
   - Share a short note describing what you changed.

Helpful tips:
- Keep examples small and easy to run.
- Avoid uploading large datasets; instead, add instructions to download them.
- Link to relevant LinkedIn posts in the post README.

This file is a simple guide — adapt it later for contributors if needed.
