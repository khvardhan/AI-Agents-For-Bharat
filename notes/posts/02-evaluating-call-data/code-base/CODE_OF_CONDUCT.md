# Code of Conduct (Short & Simple)

Welcome — we want this project to be friendly and respectful.

Expected:
- Be kind and respectful.
- Explain feedback politely and constructively.
- Help others when you can.

Not allowed:
- Harassment, insults, or hateful speech.
- Sharing private information without permission.

If you see something wrong, please contact the maintainers or open a private issue.
